# 捏盘寿司吃吃🍣

休闲握寿司网页小游戏。单文件 HTML，打开即可玩。幼龄趣味版，for Jenny。这一版把握寿司米饭捏成小船形饭台，虾、玉子烧、扇贝、军舰等也有各自的形状。

## 在线玩

打开：https://yanbinghui-cloud.github.io/niepan-sushi/

手机或电脑浏览器都可以。刷新页面即可看到最新版。

## 自己打开

下载本仓库里的 `index.html`，用浏览器直接打开即可（也可双击打开）。

## 玩法

选食材 → 滑动切鱼 → 湿手抓饭 → 点按捏紧 → 抹芥末 → 放鱼料 → 摆盘。军舰款走包海苔路线。摆盘时可换盘子、加寿司姜（粉红薄片），再撒芝麻或海苔碎。至少捏 3 贯可收工评分，会收集贴纸。

页面底部标有 `for Jenny  ·  更新于 2026-11-16 00:04（香港时间）`。
